> OCR platform using vision-language models to extract text from **low-quality scanned documents** in French, English, and Arabic — including mixed-language and right-to-left content.

- 🔒 Runs **100% offline on a local GPU** for confidential documents
- 🖼️ Adaptive preprocessing: deskew, denoise, thresholding
- 🤖 VLM post-correction with layout-preserving extraction
- 👤 Per-user document history
- 📏 **CER / WER** benchmarking against a classical OCR baseline

### 🧠 EY Agentic RAG — *TdR Intelligence*

> RAG platform for querying **hundreds of Tender Reference Documents (TdR)** in French or English, with **exact page-level citations** — aligned with **ISO/IEC 42001** AI management standards.

- 📑 Automatic TdR classification
- 📋 Structure-safe table and bullet reproduction
- 🌍 Bilingual FR / EN querying

```mermaid
flowchart LR
    A[📚 TdR Documents] --> B[🔍 Parsing<br/>PyMuPDF · OCR fallback]
    B --> C[✂️ Chunking<br/>tiktoken]
    C --> D[🧬 Embeddings<br/>BAAI/bge-m3]
    D --> E[(ChromaDB)]
    Q[❓ User Question] --> R[🔎 Retrieval]
```
